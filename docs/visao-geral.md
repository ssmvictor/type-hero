## 📝 Contexto

O repositório foi inicializado com Git, mas ainda não contém código-fonte, arquivos de configuração, manifesto de dependências ou histórico de commits. Por isso, a finalidade funcional do projeto não pode ser deduzida com segurança.

O nome provisório **Digitação** corresponde ao nome da pasta local `digitacao`; ele não representa, por si só, uma definição de produto ou requisito de negócio.

## 📋 Critérios para Completar Esta Visão

- [ ] Descrever o problema que o projeto resolverá.
- [ ] Identificar usuários, operadores e demais partes interessadas.
- [ ] Registrar os casos de uso prioritários e seus limites.
- [ ] Definir requisitos de segurança, privacidade e disponibilidade, se aplicáveis.
- [ ] Documentar a stack escolhida a partir dos arquivos reais do projeto.
- [ ] Acrescentar arquitetura, fluxos, dados e integrações somente quando existirem.

As definições que faltam estão organizadas em [Decisões Pendentes](decisoes-pendentes.md).
